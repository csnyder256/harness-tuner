# Interactive benchmark comparisons - v0.3.0

Generate a portable, interactive before/after report from two real HTP runs. The comparison pairs task IDs, validates manifests and protocol versions, shows sortable metrics and task charts, and exports JSON, CSV and print-ready HTML. Causality warnings distinguish shared seeds and matching task sets from unrelated runs.

No source prompts, raw traces, private configuration or absolute source paths enter the shareable report. Task identifiers remain visible. Unknown values remain unavailable, zero baselines have no invented percentage change, and incompatible cost units are excluded. Existing HTP v1 bundles remain readable.

## Install and upgrade

Use the versioned [deployment instructions](https://github.com/csnyder256/harness-tuner/blob/v0.3.0/DEPLOYMENT.md) and verify the release checksums before upgrading. Preserve existing user data and policy configuration.
